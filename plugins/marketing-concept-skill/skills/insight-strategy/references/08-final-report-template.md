# Final Report Contract

Use `assets/templates/final-strategy-report-template.md`. Its section names
match the controller's backstage dossier, so write the result directly into:

- `## 6. Insight Strategy`
- `## 7. Idea Platform Records`
- `## 8. Concept Records`

Do not replace the evidence pool or other dossier sections. Preserve existing
IDs and update only the strategy, platform, Concept, confidence, and decision
fields produced by this Skill.

## Required Content

The deliverable is incomplete unless it contains:

- Input Readiness and overall `Final`, `Provisional`, or `Unavailable` status
- Level 1-4 outputs with Evidence IDs
- candidate and recommended Idea Platform Records with Derivation route
- one recommended Concept and 1-2 meaningful alternatives when input is usable
- one complete Message House per retained Concept
- one Roof, exactly 2-3 Pillars, and factual Foundation items
- Evidence IDs for each Roof, Pillar, and Foundation item
- proof gaps, risks, and status for every retained Concept
- package-level recommendation rationale and rollback path

If evidence supports only one meaningful Concept, state why no alternative was
retained instead of fabricating one. If Input Readiness is `Unavailable`, stop
before Level 1 and return only missing inputs and the upstream next step.

## Status Integrity

- `Final`: all critical strategy and Concept dependencies are traceable and no
  unresolved proof gap undermines the selected promise.
- `Provisional`: useful analysis is possible, but at least one critical
  evidence, brand truth, proof edge, repeated behavior, or competitor gap
  remains.
- `Unavailable`: no traceable material can support Level 1.

A polished Idea Platform, complete template, or well-written Concept never
upgrades status by itself.
