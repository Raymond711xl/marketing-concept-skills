# Category And Volume Rules

Use this file for category extraction and output volume. Keep category summaries
descriptive and evidence-bound.

## Volume Selection

| Category | Light | Standard default | Deep |
| --- | --- | --- | --- |
| Visual materials | 3 items | 5 items | 8-12 items |
| Video | 1-2 items | 3 items | 6-10 items |
| Offline activation | 1-2 items | 3 items | 6-10 items |
| Marketing | 3 items | 5 items | 8-12 items |
| PR | 3 items | 5 items | 8-12 items |
| Social leads | 3-5 items | 5-10 items | 10-20 items |
| Report / market / competitor | 3 items | 5 items | 8-12 items |

If the user does not specify volume, use standard defaults where evidence
exists and mark missing categories as evidence gaps.

## Visual Materials

For posters, KVs, landing pages, packaging, product pages, social visuals,
event visuals, and screenshots, extract:

- Item or material name
- Evidence ID
- Material type
- Source and screenshot status
- Observation
- Composition and hierarchy
- Color, typography, imagery, and brand asset usage
- Message and CTA
- Platform adaptation
- Cross-touchpoint consistency
- Reusable evidence pattern
- Evidence gap
- Confidence

## Video

For video ads, TVCs, short videos, livestream clips, and campaign films,
extract:

- Title or asset name
- Evidence ID
- Source and link
- Raw quote or visible phrase when available
- Observation
- Core message or slogan
- Script or narrative structure
- Main audience label present in the evidence
- Visual style and craft cues
- Product role
- Platform / channel
- Evidence-supported performance indicators, if any
- Reusable evidence pattern
- Evidence gap
- Confidence

## Social Platform Restrictions

When a social platform cannot be fully accessed:

- Keep one short visible key phrase when available.
- Keep URL/citation, platform, account if visible, date if visible, and access
  limitation.
- Do not copy full posts or full comment threads.
- Mark `Screenshot status` as `not accessible`, `user needed`, or `public image
  linked` as appropriate.

Use this note when needed:

```text
Full social content requires platform access; use the link for manual verification.
```
